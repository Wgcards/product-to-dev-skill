# SSR Templates

SSR 模板统一放在这里。模板用于承载可复制项目片段、目录骨架、handoff 模板和验证清单，reference 只保留规则、边界和路由。

- `next-app-router-bff-skeleton.md`：Next App Router SSR/BFF 目录骨架、endpoint registry、gateway、service、adapter、page 和 handoff checklist。
- `server-action-mutation.md`：内部 UI mutation 的 Server Action 模板，覆盖输入校验、BFF service 调用、稳定返回结构和 revalidation。
- `ssr-common-pitfalls-checklist.md`：SSR/BFF 高频错误检查清单，覆盖 route/runtime、RSC、BFF、缓存、安全、UI runtime 和交付验证。
